# ⌨️ Chinese to Keyboard Smash Converter (Zhuyin Edition)

## ❓ What is this?
Have you ever looked at a Chinese website and thought, **"I wish I could read this as if I were frantically mashing keys on a Zhuyin keyboard while strictly using an English QWERTY layout?"**

No?

**Too bad.** That's exactly what this does.

It takes perfectly legible Chinese characters (like `你好`) and brutally massacres them into the keystrokes you *would* press if you were typing them in Zhuyin but forgot to switch your input method (like `su3 cl3`).

It turns poetry into passwords. It turns news articles into gibberish. It is the chaos agent your browser didn't ask for.

## 🌟 Features (Bugs?)
- **Instant Obfuscation:** Instantly makes any Chinese text unreadable to 99.9% of the population.
- **Educational Value (Debatable):** Technically teaches you the Zhuyin keyboard layout if you hate yourself enough to reverse-engineer it in your head.
- **Toggle on Command:** Press `T + R` to toggle. Why `T + R`? Because it stands for **T**errible **R**eadability. (Or maybe "Translate", but who cares).
- **Persistent Chaos:** Works on dynamically loaded content, so the confusion never ends.

## 🛠 Installation
1. Download this repo.
2. Go to `chrome://extensions`.
3. Enable "Developer Mode" (Hackerman mode).
4. Click "Load Unpacked".
5. Select this folder.
6. Question your life choices.

## 🎮 Usage
1. Open a webpage with Chinese text.
2. Press **`T`** and **`R`** at the same time.
3. Watch the world burn.
4. Press it again to make it stop.

## ⚠️ Warning
This extension modifies the DOM text nodes directly. It might break some sites. It might break your brain. Use at your own risk.
